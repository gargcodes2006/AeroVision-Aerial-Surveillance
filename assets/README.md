# AeroVision – Assets Directory

Place sample aerial images or videos here for the demo mode.

Supported image formats: JPG, JPEG, PNG, WEBP  
Supported video formats: MP4, AVI, MOV

## Suggested Public Datasets

- **VisDrone**: https://github.com/VisDrone/VisDrone-Dataset  
- **DOTA**: https://captain-whu.github.io/DOTA/  
- **Stanford Drone Dataset**: https://cvgl.stanford.edu/projects/uav_data/

Download an aerial image from any of these public datasets and place it here
as `sample_aerial.jpg` to enable the built-in demo mode.
